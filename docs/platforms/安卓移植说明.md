# Android 移植约束

> 文档分类：平台适配。Android 不是首发目标。

Android 不是首发目标，但工程从第一天保留移植能力。

## 可以直接复用

- 全部纯 C# 规则、AI、提示和托管
- 确定性随机数与回放格式
- 豆子、角色、战绩和规则配置
- 大部分 Godot 场景、动画与音频

## 需要单独适配

- 横屏、安全区、圆角屏和不同长宽比
- 点击、拖动、长按与返回键
- 应用切到后台后的暂停和安全保存
- Android SDK/JDK、Godot .NET 导出模板与应用签名
- APK/AAB 打包、真机性能与不同厂商兼容测试
- 如果允许玩家导入本地角色图，需要适配系统文件选择器和存储权限

## 当前编码约束

- 规则层不接收鼠标坐标或 Godot 输入事件，只接收游戏命令。
- UI 优先使用 Godot `Control` 与标准 `Button`，让鼠标点击和触摸点击走同一路径。
- 可点击目标按触屏尺寸设计，不依赖鼠标悬停才能理解状态。
- 关键布局位于 960×540 安全区，额外宽度只展示背景。
- 存档只通过统一存档服务访问 `user://`，不写死桌面系统路径。
- 游戏失去焦点或进入后台时，不在规则操作中间保存半个状态。

这些约束能把未来 Android 工作控制在平台适配层，不需要重写玩法。

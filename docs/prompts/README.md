# 美术提示词库

这里保存可复用、可追踪版本的美术生成提示词。提示词按资产类型分类，不能直接散放在 `docs/prompts/` 根目录。

概念图只用于确定气氛和构图，不直接当作正式资产。生成正式资产时，应把对应概念图作为参考图，并明确要求去除其中已经烘焙的人物、牌面、文字和 UI。

## 分类索引

| 资产类型 | 当前用途 | 入口 |
| --- | --- | --- |
| 背景 | 大厅、斗地主、麻将的环境底图与宽屏延展 | [backgrounds/README.md](backgrounds/README.md) |
| 交互 UI | 仅生成装饰语言参考，功能控件仍由 Godot 实现 | [ui/README.md](ui/README.md) |
| 人物 | 当前使用程序占位，正式人物提示词暂缓 | [characters/README.md](characters/README.md) |

## 使用规则

1. 先读取对应类型 README 和通用基线，再使用具体提示词。
2. 每次实际生成或编辑资产都要在当次任务档案中记录提示词版本、参考图、选用结果和必要的人工调整。
3. 生成图中的文字、数字、图标、扑克牌和麻将牌默认不可信，不允许直接承担游戏语义。
4. 未被采用的批量候选图不进入正式资产目录；正式选中的源文件和成品使用清晰名称并记录来源。

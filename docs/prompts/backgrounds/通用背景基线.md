# 通用背景基线 v1

## 生产规格

- 画面风格：高清像素风二次元游戏环境，保留清晰像素簇和硬边细节，但不模拟极低分辨率马赛克。
- 核心构图：中央 16:9，成品目标为 `2560×1440`。
- 手机宽屏母版：在不改变中央构图的前提下向左右延展，目标为 `3200×1440`；中央 `2560×1440` 必须能够独立裁出。
- 逻辑坐标：程序按 `960×540` 排版，提示词中的百分比都相对于中央 16:9 安全区。
- 色彩方向：深夜蓝绿色为主，暖黄局部灯光，少量金色与红色点缀；避免纯黑区域吞掉桌沿。

## 通用提示词

```text
请制作一张可直接用于横屏二次元单机棋牌游戏的生产级环境底图。采用高清像素风：轮廓清楚、像素簇有意设计、材质细节克制，整体像高品质现代像素游戏，而不是低分辨率马赛克，也不是模糊的油画或普通插画。

画面必须是纯环境层。不要出现任何人物、人物剪影、头像、手臂、宠物、扑克牌、麻将牌、筹码、骰子、金币、按钮、面板、进度条、对话气泡、可读文字、数字、商标、水印或伪造界面。不要把参考图中已有的角色和 UI 保留下来。所有将来会变化、被点击或显示游戏状态的元素都由程序叠加。

维持固定、清楚、适合程序叠加二维对象的透视关系。桌面和主要交互区域不要放高频花纹、强反光、散落物品或高对比装饰。画面上下边缘保持较低对比度，确保浅色文字和深色半透明面板都可读。光源方向一致，不使用景深虚化，不使用电影黑边。

先生成中央 16:9 主构图。若执行宽屏延展，只向左右补充同一房间中的墙面、书架、窗帘或低对比装饰，不移动、不缩放、不重绘中央 16:9 内容；宽屏目标比例为 20:9，中央 16:9 必须可以完整裁出。
```

## 验收底线

- 中央构图没有人物、牌、麻将、文字或 UI 残留。
- 桌面透视能够让程序按固定坐标摆放牌。
- 中央 16:9 裁切与 20:9 完整图都不切断主要家具。
- 上下 HUD 区域没有过亮光源或高频细节。
- 同一房间内的直线、桌沿和家具不存在明显生成畸变。

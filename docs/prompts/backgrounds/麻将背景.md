# 麻将背景提示词 v1

## 参考与定位

- 参考图：`美术概念/麻将image.png`。
- 默认时间：深夜，与大厅、斗地主房间保持同一地点的视觉连续性。
- 镜头：接近俯视但仍能看到桌沿厚度的固定四人麻将镜头。

## 场景提示词

将以下内容与[通用背景基线](通用背景基线.md)一起使用：

```text
制作同一间深夜城市牌社中的四人麻将对局环境。主体是一张接近正方形的自动麻将桌，墨绿或深青绿色连续绒面，暖棕木质外沿，四条边透视稳定、方向明确。桌体占中央 16:9 安全区约 10% 至 90% 宽、10% 至 77% 高。镜头接近俯视，四个座位的牌墙、牌河、副露和手牌以后都能由程序沿固定直线排列。

桌面必须完全空白，不要生成任何麻将牌、牌墙、骰子、点棒、筹码、庄家标、方向字、计分屏幕、洗牌口文字或装饰徽章。桌面中央约 41% 至 59% 宽、34% 至 56% 高预留给程序生成的中央信息盘，四周保持均匀、低纹理的绿色桌布。

顶部 38% 至 62% 宽、10% 至 25% 高，左侧 2% 至 16% 宽、35% 至 57% 高，右侧 84% 至 98% 宽、35% 至 57% 高是三名对手头像和牌墙预留区；底部 10% 至 98% 宽、69% 至 97% 高用于玩家头像、14 张手牌、向听提示与吃碰杠和牌按钮。房间装饰只出现在桌外和画面角落，并延续大厅的书架、夜景与暖灯。

画面服务于大众麻将、四川血战和日式立直三种模式，因此不要在背景中固定任何单一规则专属标志。所有规则差异都由程序界面表现。
```

## 拒绝条件

- 桌面自动出现麻将牌、方向字、骰子、点棒或电子数字。
- 桌边透视无法让四个方向的牌保持平行排列。
- 使用了只属于日麻、川麻或某个地方规则的固定装饰。

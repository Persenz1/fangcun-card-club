# 大厅背景提示词 v1

## 参考与定位

- 参考图：`美术概念/大厅dark.png` 为主，`美术概念/大厅bright.png` 仅用于理解房间结构。
- 默认时间：深夜。
- 镜头：正面平视略微俯视的固定广角镜头，不使用夸张广角畸变。

## 场景提示词

将以下内容与[通用背景基线](通用背景基线.md)一起使用：

```text
场景是一间温暖、有人长期生活痕迹但当前无人的城市牌社休息室。窗外是深蓝夜空和克制的蓝紫色城市灯光，室内由暖黄吊灯、书架小灯和少量青绿色环境光照明。房间气质舒适、安静、略带现代日系公寓感，不像赌场、酒吧或商业游戏厅。

保持参考图的总体功能关系：左侧是一张较低的方形麻将桌或展示台，右侧是一张圆形纸牌桌，中央是一条开阔通道和角色站位，后方有沙发与大窗，边缘可以放书架、冰箱、植物和猫窝等静态家具，但不要出现猫或其他生物。两张桌子上都必须完全空白，不摆放麻将牌、扑克牌、筹码、骰子、铭牌或发光图标。

中央 41% 至 59% 宽、22% 至 76% 高的区域是人物立绘预留区：保持轮廓干净，避免灯具、植物、桌角或强烈窗框穿过人体轮廓。左侧 6% 至 37% 宽、29% 至 72% 高以及右侧 63% 至 94% 宽、29% 至 72% 高会覆盖大型游戏入口按钮，背景可以提供桌子轮廓，但不能放任何需要被看清的叙事细节。顶部 0% 至 18% 是玩家资料和豆子栏，底部 78% 至 100% 是状态和导航栏，均保持低对比。

画面应让左侧青绿色麻将入口、右侧暖红色斗地主入口以及中央角色即使后续完全由程序叠加，也能自然融入同一个空间。
```

## 拒绝条件

- 中央站位被家具、灯光或窗框切割。
- 两张桌上自动生成了牌、筹码或文字。
- 房间变成赌场、酒馆、赛博机房或过度霓虹的街机厅。

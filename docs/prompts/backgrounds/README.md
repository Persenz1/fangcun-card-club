# 背景提示词

背景由生成模型提供环境与氛围，人物、牌面和功能性 UI 不进入背景位图。

## 使用顺序

1. 阅读并使用[通用背景基线](通用背景基线.md)。
2. 叠加一个具体场景提示词。
3. 先确认中央 16:9 构图，再执行左右延展。

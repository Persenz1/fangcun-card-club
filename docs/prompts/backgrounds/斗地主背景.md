# 斗地主背景提示词 v1

## 参考与定位

- 参考图：`美术概念/斗地主image.png`。
- 默认时间：深夜，与大厅属于同一间牌社。
- 镜头：固定的中高机位，能够同时看到完整椭圆桌面和少量房间环境。

## 场景提示词

将以下内容与[通用背景基线](通用背景基线.md)一起使用：

```text
制作同一间深夜城市牌社中的斗地主对局环境。主体是一张横向椭圆形纸牌桌，深海军蓝或墨蓝色连续绒面，厚实暖棕木质桌沿。桌子占中央 16:9 安全区约 12% 至 88% 宽、15% 至 75% 高，透视左右对称，桌沿曲线稳定，没有缺口和畸变。桌面必须完全空白、平整，不要印花、徽章、字样、划线或散落物。

房间边缘延续大厅的书架、大窗、夜景、暖黄台灯与青蓝环境光，使玩家能认出是同一牌社，但环境细节只放在桌外。左侧和右侧约 3% 至 16% 宽、19% 至 40% 高是对手头像与剩余牌数预留区，顶部 25% 至 75% 宽、0% 至 14% 高是底分和倍数栏，底部 10% 至 96% 宽、61% 至 97% 高会覆盖玩家手牌和操作按钮；这些区域后方保持低对比。

桌面中央约 38% 至 62% 宽、35% 至 54% 高用于显示本轮出牌，必须保持均匀暗色，不放灯光热点或桌面纹理。只生成房间、灯光、椭圆桌体和静态家具；不要生成任何座椅上的人物，也不要暗示手臂伸入画面。
```

## 拒绝条件

- 椭圆桌透视不对称，桌沿曲线破损或桌面可用范围过小。
- 桌面出现扑克牌、筹码、花纹、文字或中心徽章。
- 底部手牌区被高亮桌沿或强烈反光干扰。

# 装饰框与材质参考稿提示词 v1

## 用途

为 Godot `StyleBoxFlat`、九宫格边框和少量装饰角花提供造型参考。生成结果不直接包含功能按钮，也不承担任何文字或图标。

## 提示词

```text
制作一张高清像素风二次元棋牌游戏 UI 装饰语言参考板，纯色中性背景，所有组件彼此分离、正面平视、没有透视。色板限定为深海军蓝、墨青绿、暖暗红、米白和少量旧金色，气质温暖、精致、适合深夜牌社，不要赌场奢华感。

展示少量可复刻的装饰结构：一种深蓝信息面板边框、一种青绿色普通操作框、一种暖红色主要操作框、一组四角金色角花，以及两种细分隔线。边框中心保持完全空白，边缘粗细一致，左右和上下对称，适合之后人工重绘成可拉伸九宫格。

不要出现文字、数字、汉字、英文字母、扑克牌花色、麻将字样、人物、头像、按钮标签、金币、礼物、奖杯、齿轮、商标、水印、阴影粘连或完整游戏截图。不要生成几十种近似变体，只需要少量清晰、相互一致的设计。
```

## 使用限制

- 只选择一种边框语言，由程序重新实现；不直接裁切模糊或不对称的生成边框。
- 设置、礼物、提示等语义图标以后使用人工 SVG 或像素图集，不从本参考稿提取。

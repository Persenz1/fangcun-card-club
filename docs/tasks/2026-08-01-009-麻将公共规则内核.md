## 目标

建立三种麻将共同且稳定的纯 C# 基础：34 种牌与实体牌、确定性牌墙、四个座位、手牌、副露、牌河、摸打与鸣牌原语、标准和牌分解、七对/国士形判定和听牌枚举，供大众、四川与日麻模块组合使用。

## 范围

本任务包含新的 `Game.Mahjong` 规则项目、公共领域对象、基础桌面状态、和牌形算法与测试项目。

本任务不包含任何具体玩法的番型、计分、特殊流程、AI 或 Godot 接入；大众麻将、四川血战和日麻分别在后续独立项目中使用公共模型，不向公共层加入变体条件分支。

## 关键决策

- 公共牌集为万、筒、条、四风和三元共 34 种、每种四张；花牌与赤宝牌不是三套玩法都稳定共享的基础，本层不预置。
- 实体牌由牌种和 0–3 副本号唯一标识；规则组合只按牌种计数，牌墙和牌河仍保留实体身份。
- 公共和牌算法只回答结构：四组面子加一对、七对或国士无双；具体玩法是否允许以及对应番数由各自模块决定。
- 公共桌面只提供摸牌、弃牌、建立吃碰杠副露和只读快照等原语，不决定反应优先级、振听、定缺、血战退出或结算。
- 所有牌墙随机顺序继续使用项目现有 `IDeterministicRandom`。

## 实际改动

- 新增 `Game.Mahjong` 纯 C# 项目并加入解决方案，只引用 `Game.Core` 的确定性随机接口。
- 新增 34 种 `MahjongTileKind`、花色/数字/幺九字牌语义工具、0–3 副本号实体牌和 136 张有序/确定性洗牌牌集。
- 新增 `MahjongWall`，支持普通活牌墙、日麻 14 张王牌区和最多四次补张；每次补张同步减少一张可摸活牌。
- 新增四座位、`MahjongHand`、五类吃碰杠副露、带摸切/被鸣标记的牌河与 `MahjongTableState` 摸打鸣牌原语及只读快照。
- 新增通用弃牌、鸣牌、暗杠、加杠、和牌与跳过命令类型，但不在公共层决定任何变体合法性。
- 新增 `MahjongHandAnalyzer`，枚举普通四面子一雀头的全部分解，并按调用方选项识别七对、国士无双和列出所有实际可用听牌。
- 新增 `Game.Mahjong.Tests` 并加入解决方案，覆盖牌集、牌墙、起手、摸切、牌河、碰牌和三类和牌结构边界。
- 同步根 README 工程目录与文档索引。

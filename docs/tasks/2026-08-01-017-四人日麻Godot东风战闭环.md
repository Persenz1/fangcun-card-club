# 2026-08-01-017：四人日麻 Godot 东风战闭环

- 状态：已完成
- 日期：2026-08-01
- 负责人：Codex
- 关联文档：[日式立直麻将规则](../rules/日式立直麻将规则.md)、[麻将混合渲染](../architecture/麻将混合渲染.md)、[四川血战 Godot 试玩闭环](2026-08-01-016-四川血战Godot试玩闭环.md)

## 目标

将四人日式立直麻将适配器接入共用 Godot 麻将桌，让玩家能对三名 AI 完成整场东风战（含规则触发的南场延长），直到整场排名与最终点数。

## 范围

本任务包含大厅日麻入口、吃碰杠/立直弃牌/荣和自摸/跳过的精确合法选项、振听与立直状态、场风/自风/局数/本场/供托/点数、宝牌指示实体牌、每局役种符番与支付摘要、连庄/荒牌/途中流局后续局，以及真实 Godot 完整场烟测。

本任务不修改日麻规则、役种、符番或结算实现，不向共用 Godot 控制器添加抢杠、多家荣和、岭上或流局的合法性判断，不调整固定相机和桌面标定。

## 关键决策

- 立直弃牌与普通弃牌保留为两个独立合法选项，表现层不以听牌或点数自行推导。
- 日麻引擎在每局结束的同一已接受命令中开始下一局；Godot 用事件节拍显示上一局结果，同时只渲染新快照，不缓存第二份规则状态。
- 多家荣和、抢杠、杠宝牌、岭上、荒牌和途中流局仅通过日麻规则事件和结果显示。

## 实际改动

- 启用大厅“四人日麻”入口，通过模式工厂创建独立 `RiichiMahjongGameSession`，共用 Godot 控制器不增加日麻合法性分支。
- 普通弃牌仍使用真实手牌选择；吃、碰、大明杠、暗杠、加杠、荣和、自摸、跳过、九种九牌和每个“立直打 X”均作为应用层给出的独立精确选项。
- HUD 从日麻快照显示场风/局数、本场、供托、剩余牌、四家点数、自风、庄家、立直/双立直、待成立立直与振听状态。
- `MahjongBoard3D` 使用快照中宝牌指示列表创建真实牌节点；开杠后的新指示牌按日麻事件节拍更新，里宝牌中牌数继续由日麻计分结果中的役种条目显示。
- 新增持续可见的“上一局”面板，在日麻引擎立即进入下一局后，仍从当前快照的 `LastHandResult` 显示荣和/自摸/荒牌/途中流局原因、多家和牌、役种、宝牌/里宝牌、符番、限制名与局分。
- 引擎每局结束后的新手牌、新牌墙、场风/局数、连庄、本场和点数直接刷新；整场结束层显示四家排名与最终点数。
- 新增一项日麻应用层整场边界测试，以固定种子验证至少四局转换、整场事件、四家排名和 100000 点守恒。
- `verify.sh` 新增固定种子日麻真实 Godot 完整场烟测，同步根 README 的三种麻将可玩状态与试玩说明。

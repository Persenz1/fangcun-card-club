## 目标

补齐《方寸牌社》的本地开发环境、可扩展工程骨架、自动测试和 Windows x64 导出链路。

## 范围

包含 Godot/.NET 工具链、解决方案分层、确定性随机数、基础牌模型、Godot 灰盒场景、测试和构建脚本。不包含完整斗地主规则、AI、存档或正式美术实现。

## 关键决策

- 产品工作名定为《方寸牌社》，代码名为 `FangcunCardClub`。
- 工具链安装在被 Git 忽略的 `.tools/`，不修改系统范围配置。
- Godot 表现层只引用应用层和规则模块；纯 C# 规则代码不依赖 Godot。
- 逻辑画布使用 960×540，输入优先使用鼠标和触控共用的标准控件。
- 固定项目自己的确定性随机算法，不依赖 `System.Random` 的跨版本行为。

## 实际改动

- 安装 Godot 4.7.1 .NET、.NET SDK 10.0.302 和 Godot .NET 导出模板。
- 建立 `FangcunCardClub.sln`、Godot 主项目、三个源代码项目和两个测试项目。
- 实现 SplitMix64、标准 54 张牌堆、可复现洗牌及斗地主阶段枚举。
- 建立大厅灰盒启动场景、角色定义示例和深夜主题定义。
- 增加环境、验证、Godot 启动和 Windows 导出脚本。
- 将仓库目录从 `doudizhu` 更名为 `fangcun-card-club`。

## 验证

- `./scripts/verify.sh`：构建成功，0 警告、0 错误；5 个测试全部通过；Godot 资源导入和主场景无界面启动成功。
- `./scripts/export-windows.sh`：成功生成 Windows x64 PE 可执行文件、PCK 和 .NET 数据目录。
- `file artifacts/windows/FangcunCardClub.exe`：识别为 Windows x86-64 GUI 可执行文件。
- `./scripts/dotnet.sh format FangcunCardClub.sln --verify-no-changes --no-restore`：通过。

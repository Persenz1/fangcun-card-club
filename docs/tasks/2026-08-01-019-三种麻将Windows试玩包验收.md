## 目标

对本轮三种麻将 Godot 可玩闭环做最终回归与 Windows x64 发布验收，产出包含 EXE、PCK 和完整 .NET 运行时目录的可分发压缩包。

## 范围

本任务包含导出脚本的包结构验证、Windows x64 导出与 ZIP 生成、压缩包完整性检查、最终 `verify.sh`、Git 忽略项与远端 main 同步检查。

本任务不改动任何玩法规则、桌面标定或美术布局。

## 关键决策

- 发布产物仍放在 Git 忽略的 `artifacts/windows/`，仓库只提交可重复的导出和验收流程。
- 压缩包只从本次新导出的临时目录生成，避免旧产物混入；生成前明确检查 EXE、PCK 与 .NET 运行时目录。

## 实际改动

- 改造 `scripts/export-windows.sh`：Release 构建和 Godot 导出均在本次新建的临时目录中完成，不从已有 `artifacts/` 内容打包。
- 导出后强制检查非空 EXE/PCK、唯一 .NET 运行时目录、Godot 主程序集、公共应用层、斗地主与三种麻将程序集，以及 `coreclr`/`clrjit`/`hostfxr`/`hostpolicy` 自包含组件。
- ZIP 生成后立即解压到第二个临时目录，与原导出目录做逐文件比对；只在一致时替换最终 ZIP 并保留已验收解压目录。
- 更新根 README 的导出命令、精确产物路径与脚本职责，在平台索引记录 Windows x64 自包含试玩包验收规则。

# 2026-08-01-006：斗地主牌型与合法出牌

- 状态：已完成
- 日期：2026-08-01
- 负责人：Codex

## 目标

完成斗地主纯 C# 规则内核的第一段可验证能力：准确识别和比较已冻结的经典牌型，并从玩家手牌枚举所有能够首出或压过上一手的合法出牌，供后续状态机、提示、托管和 AI 共用。

## 范围

本任务包含牌型值对象、牌型识别、同型与炸弹比较、合法出牌枚举、正式规则文档和聚焦边界的自动测试。

本任务不包含叫抢地主状态机、发牌编排、出牌回合状态、结算、AI、Godot 界面接入、豆子或存档；这些能力在后续独立任务中接入本任务提供的唯一合法操作来源。

## 关键决策

- 规则层继续保持纯 C#，不引用 Godot 或表现层类型。
- 牌型只保存比较和展示所需的规范化信息，不镜像保存第二份手牌状态。
- 合法出牌由牌型结构直接组合生成，不遍历最多 20 张手牌的全部子集。
- 对规则存在常见分歧的带牌细节必须先写入正式规则文档，再作为识别与枚举的共同依据。

## 实际改动

- 新增 `CardPatternKind` 与 `CardPattern`，用牌型、主体点数、连续组数和总张数表达规范化比较信息。
- 新增 `PatternDetector`，识别单张、对子、三张、三带、顺子、连对、三种飞机、两种四带、炸弹和王炸，并统一处理 `2`、王和带牌边界。
- 新增 `PatternComparer`，实现同型同长度比较、炸弹跨牌型压制和王炸最高规则。
- 新增 `DoudizhuMove` 与 `LegalMoveGenerator`，按点数结构生成首出或跟牌候选，再由识别器确认并展开为具体实体牌组合。
- 新建正式《斗地主规则》，冻结牌点、14 类出牌牌型、带牌边界、比较规则和合法操作唯一来源。
- 新增固定牌例、比较优先级、实体牌组合数和小手牌穷举对照测试。
- 同步文档索引和根 README 工程目录。

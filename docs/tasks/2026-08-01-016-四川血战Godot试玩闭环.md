# 2026-08-01-016：四川血战 Godot 试玩闭环

- 状态：已完成
- 日期：2026-08-01
- 负责人：Codex
- 关联文档：[四川麻将规则](../rules/四川麻将规则.md)、[麻将混合渲染](../architecture/麻将混合渲染.md)、[大众麻将 Godot 试玩闭环](2026-08-01-015-大众麻将Godot试玩闭环.md)

## 目标

在不向大众麻将或日麻渗入四川条件的前提下，将四川血战会话适配器接入共用 Godot 麻将桌，让玩家可完成换三张、定缺、血战摸打、赢家退出、即时杠分和最终结算。

## 范围

本任务包含大厅四川模式入口、玩家三张实体牌选择、换牌方向/定缺/缺门强制弃牌提示、碰杠胡和一炮多响事件、已和座位退出状态、刮风下雨分数、查花猪/查大叫结算，以及真实 Godot 完整局烟测。

本任务不修改四川规则、大众会话或日麻会话，不接入本地恢复，不调整固定相机或另建桌面坐标。

## 关键决策

- 共用 Godot 控制器只根据通用选牌操作、动态选项和座位状态显示；换三张、定缺、赢家退出和结算文本均由四川适配器转换。
- 换三张的可选牌与组合完全来自合法操作列表，牌桌只做精确实体牌集合匹配。
- 即时胡牌与杠分通过事件节拍显示，最终查花猪/查大叫只消费 `SichuanMahjongSettlement`。

## 实际改动

- 大厅麻将区拆分为大众、四川与日麻三个模式入口，本任务启用四川血战，共用 `MahjongTableController` 通过模式工厂创建独立四川会话。
- 共用选牌区直接消费四川适配器给出的换三张合法组合；点击提示可精确选中三张实体牌，定缺按钮同样由合法选项动态生成。
- 座位面板按四川快照显示已换牌、定缺门、在战/已和退出状态和实时零和分数；已和座位的手牌与座位状态继续由同一快照刷新。
- 四川鸣牌事件显示碰/点杠/补杠/暗杠及“刮风下雨”当次分数，和牌事件显示番型、番数和赢家退出；多家点炮依次消费规则事件。
- 最终结算层显示全部即时和牌、查花猪、查大叫听牌座位与四家总分，未在 Godot 重算任何四川条件。
- 新增一项应用层完整血战边界测试，验证换牌/宣言/最终事件映射、命令推进和结算零和。
- `verify.sh` 新增固定种子四川真实 Godot 完整局烟测，同步根 README 可玩范围和试玩说明。

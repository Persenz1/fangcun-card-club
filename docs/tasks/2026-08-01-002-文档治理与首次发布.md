## 目标

建立强制文档留档与目录同步规则，检查忽略配置，并把工程首次发布到 `Persenz1/fangcun-card-club`。

## 范围

包含文档分类、索引、任务模板、历史任务补档、README 工程目录、提交钩子、`.gitignore` 审核、首次 Git 提交和推送。不修改游戏玩法实现。

## 关键决策

- `docs/` 根目录只保留总索引 README，其他文档必须分类存放。
- 每个任务必须创建或更新 `docs/tasks/` 中的任务记录。
- 任何文件新增、删除或重命名都要求同一提交更新根 README 的工程目录。
- 规则同时写入 `AGENTS.md`、文档索引和版本化 pre-commit 钩子，减少只靠口头约定失效的风险。
- 本地工具、缓存、构建结果和导出包不得进入 Git。
- VS Code 只提交共享的 `extensions.json` 与 `tasks.json`，其他个人配置默认忽略。
- 工程遵循必要复杂度原则：不堆叠重复校验、状态哈希、多层兜底和无需求支撑的抽象，只保留必要测试与清晰模块边界。

## 实际改动

- 把程序规划和 Android 说明分别移动到 `architecture/` 与 `platforms/`。
- 新建产品、架构、规则、平台、美术、任务和模板分类索引。
- 新建任务记录模板及两份首日任务档案。
- 扩充根 README，加入完整工程目录和强制同步规则。
- 增加文档治理检查脚本与版本化 Git 提交钩子。
- 审核并补充 `.gitignore`。
- 使用 `.gdignore` 阻止 Godot 扫描纯 .NET 与测试源码，避免生成无意义的资源 UID。
- 把高内聚低耦合、禁止越界和反过度设计规则写入根 README 与 `AGENTS.md`，并移除规划中的逐步状态哈希。

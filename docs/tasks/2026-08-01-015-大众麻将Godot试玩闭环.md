# 2026-08-01-015：大众麻将 Godot 试玩闭环

- 状态：已完成
- 日期：2026-08-01
- 负责人：Codex
- 关联文档：[大众麻将规则](../rules/大众麻将规则.md)、[麻将混合渲染](../architecture/麻将混合渲染.md)、[麻将公共应用与表现边界](2026-08-01-014-麻将公共应用与表现边界.md)

## 目标

将大众麻将独立会话适配器接入现有 Godot 麻将场景，让屏幕下方玩家能对三名 AI 从开局完整玩到和牌或流局、结算并再来一局。

## 范围

本任务包含大众麻将模式入口、玩家真实手牌与选牌、合法弃牌/吃碰杠胡/跳过选项、提示与托管、AI 节拍、结算与再来一局，以及手牌、摸牌、副露、牌河和剩余牌墙的真实 3D 牌节点刷新。

本任务不包含四川特殊流程、日麻整场 HUD、本地恢复或美术精调；不修改固定相机、桌面标定与背景构图。

## 关键决策

- `MahjongBoard3D` 只接受 `MahjongTableView` 只读表现数据，不持有或推导规则状态。
- 所有手牌、副露、牌河和牌墙位置仍由 `MahjongTableCalibration` 的逻辑画布坐标投射，不新增世界坐标常量。
- 多个吃法或杠法直接按应用层 `MahjongActionOption` 显示独立选项，Godot 不拼接合法性。

## 实际改动

- 新增 `MahjongTableController`，把现有麻将场景接到 `IMahjongGameSession`；本地玩家固定为东座/屏幕下方，其他三家按应用层节拍由既有 AI 驱动。
- 完成真实选牌和弃牌，并将吃、碰、明杠、暗杠、加杠、点炮胡、自摸胡与跳过直接按 `MahjongActionOption` 动态生成明确按钮；多个吃法/杠法不经 Godot 判断或合并。
- 提示和托管均使用应用会话的 `SuggestedActionId`，玩家选牌只与当前合法选项精确匹配。
- 重构 `MahjongBoard3D`，仅消费只读 `MahjongSessionView`；按实际手牌数、副露、未被鸣取牌河和剩余牌墙创建真实 `MahjongTile3D` 节点，对家暗牌仅显示牌背。
- 在 `MahjongTableCalibration` 内补齐四家手牌线、副露线、宝牌线和牌河网格投射；标线与实际摆牌继续共用该唯一数据源，固定相机与背景未改。
- 接入摸牌、弃牌、鸣牌、和牌和回合切换的牌节点抬起强调、座位指示与统一事件节拍，并新增番型/分数结算层和再来一局。
- 大厅麻将入口改为大众麻将完整单局；命令行支持固定麻将种子与模式参数。
- 新增 `scripts/smoke-mahjong.sh`，并把大众麻将固定种子真实 Godot 完整局烟测加入 `verify.sh`。
- 同步根 README 当前状态、试玩说明、工程目录与麻将混合渲染架构说明。

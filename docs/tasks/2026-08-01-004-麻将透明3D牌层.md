# 2026-08-01-004：麻将透明 3D 牌层

- 状态：已完成
- 日期：2026-08-01
- 负责人：Codex
- 关联文档：[界面与背景规格](../art/界面与背景规格.md)、[程序实现规划](../architecture/程序实现规划.md)、[麻将混合渲染](../architecture/麻将混合渲染.md)

## 目标

在现有 2D 房间与麻将桌背景上加入透明 3D 麻将牌层，完成固定相机、共用牌模、四方牌墙、牌河和玩家手牌的技术验证，并保持 2D HUD 正常交互。

## 范围

本任务包含：

- 一个可复用的带厚度低面数麻将牌模型和简单卡通材质。
- 与当前麻将桌透视相匹配的固定相机和透明 3D 渲染层。
- 四家牌墙、示例牌河、玩家 14 张手牌和选牌抬起反馈。
- 玩家手牌的鼠标/触控命中与现有提示按钮联动。
- 1080p/高分辨率缩放、Godot 启动和 Windows 导出验证。

本任务不包含：

- 麻将桌或房间的 3D 建模。
- 正式麻将牌面纹理图集、人物、规则状态机和摸打牌动画。
- 物理碰撞、刚体模拟、自由相机或复杂光影系统。

## 关键决策

- 房间与麻将桌继续使用一张固定角度的 2D 背景；只有麻将牌进入 3D。
- 3D 层位于背景和 2D HUD 之间，使用透明 `SubViewport` 合成。
- 相机固定，不允许玩家旋转；牌的位置和旋转由程序直接设置，不使用物理模拟。
- 所有牌实例共用一个模型结构，仅牌面显示和位姿不同。
- 本阶段牌面使用程序生成的准确文字占位，不调用生成模型制作有规则语义的牌面。
- 初版按电脑端定标：玩家手牌约占中央安全区宽度 `62%–66%`，牌墙和牌河使用更小一级的尺寸；高分辨率只提升渲染清晰度。

## 实际改动

- 新增 `MahjongTile3D`：所有实例共用牌体、牌面和牌背资源，仅玩家手牌创建碰撞体；支持鼠标与触控命中和单牌上抬反馈。
- 新增 `MahjongBoard3D`：建立固定相机、双向卡通灯光、四方双层牌墙、四组示例牌河和 14 张玩家手牌。
- 新增 `Mahjong3DLayer`：在透明 `SubViewport` 内渲染 3D 麻将，根据实际窗口的中央 16:9 核心尺寸提高渲染分辨率，并换算鼠标与触控坐标。
- 改造麻将场景：保留 2D 房间与桌体背景，移除旧的 2D 方块牌占位，在 3D 层上方继续使用座位、计分、状态和操作按钮。
- 将提示按钮与 3D 选牌连接；界面只显示玩家意图，不在表现层判断舍牌合法性或向听变化。
- 按 1280×720 电脑端实拍调整牌墙、牌河和手牌比例，并移动中央信息盘，保证四方牌河均可见。
- 新增混合渲染架构文档，并同步 README 工程目录、美术尺寸规范、背景候选用途与文档索引。

# 2026-08-01-005：麻将牌桌标定与布局

- 状态：已完成
- 日期：2026-08-01
- 负责人：Codex
- 关联文档：[麻将混合渲染](../architecture/麻将混合渲染.md)、[界面与背景规格](../art/界面与背景规格.md)

## 目标

以 `美术概念/麻将image.png` 和当前无牌桌面背景的内框透视为唯一布局参考，建立可见的桌面标线和统一屏幕标定坐标，缩小并重新摆放全部麻将牌，形成后续可逐点调整的麻将牌桌布局雏形。

## 范围

本任务包含：

- 标定桌面内框、手牌带、四方牌墙和牌河安全区。
- 将 3D 摆位从散落世界坐标改为逻辑画布标定点投射到桌面平面。
- 按概念图比例统一缩小玩家手牌、牌墙和牌河。
- 可开关的开发标线，供后续逐点调整。

本任务不包含：

- 选牌、打出、摸牌、手牌重排或其他打牌交互。
- 麻将合法性、向听、吃碰杠胡或轮次规则。
- 正式牌面图集、角色美术和结算演出。
- 斗地主桌面交互扩展。

## 关键决策

- 背景桌面内框是摆位的权威来源，概念图只用于确定各功能区在内框中的相对比例。
- 所有关键位置记录为 `960×540` 逻辑画布坐标，再由固定相机射线投到 3D 桌面平面。
- 标线与实际摆牌共用同一组标定数据，禁止维护两套近似坐标。
- 玩家手牌使用标定线确定位置，但牌面固定朝向屏幕并连续并排，不模拟桌面倾角。
- 本轮只完成全桌布局雏形，打牌功能留到后续独立任务。

## 实际改动

- 根据无牌背景的绒布色块边界和概念图牌组范围，将桌面内框、摆牌安全区、四面牌墙、四个牌河、中央信息盘和玩家手牌位置标定到 `960×540` 逻辑画布。
- 新增 `MahjongTableCalibration` 作为标线与摆牌的唯一坐标来源。
- 新增 `MahjongTableGuide`，用青、黄、橙、紫、绿五类线框显示桌面边界与功能区，并在麻将工具栏增加“标线”开关。
- `MahjongBoard3D` 改为用固定相机射线将逻辑坐标投到桌面平面，移除牌墙、牌河和手牌散落的近似世界坐标。
- 玩家手牌调整为基准牌模 `84%`、屏幕朝向、14 张连续并排；牌墙和牌河分别缩到 `48%` 与 `58%`。
- 保留已有的选牌占位反馈，但按本轮边界没有新增打出、摸牌、手牌重排或麻将规则。

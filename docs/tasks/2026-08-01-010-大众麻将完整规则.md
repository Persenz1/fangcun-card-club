## 目标

在 `Game.Mahjong` 公共模型之上完成一局可独立运行的大众麻将：摸打、吃碰杠胡、反应优先级、流局、独立番型与零和结算、基础 AI 和批量确定性对局。

## 范围

本任务包含新的 `Game.Mahjong.Standard` 项目、正式规则文档、命令/事件/快照、合法操作枚举、番型计分、基础 AI 和测试项目。

本任务不包含四川定缺/血战、日麻役符/振听，也不修改 Godot 麻将布局或接入 3D 牌层。

## 关键决策

- 采用 136 张无花牌四人休闲规则；允许普通形、七对和十三幺，无最低番限制。
- 点炮反应优先级为和牌高于碰/明杠高于吃；同级按距放铳者顺时针最近者优先，一炮只和一家。
- 吃仅限放铳者下家；碰、明杠与点炮胡可来自任意其他座位；暗杠/加杠后从牌墙尾补一张。
- 本规则集不加入抢杠胡、报听、花牌或地方附加买码，避免把未命名的平台变体混入“大众麻将”。
- 番型和结算只在 `Game.Mahjong.Standard` 实现，公共层继续只负责结构分析。

## 实际改动

- 新增 `Game.Mahjong.Standard` 纯 C# 项目，仅组合 `Game.Mahjong` 公共模型，不向公共层写入大众麻将条件。
- 新增大众麻将阶段、合法操作值、只读快照、命令结果与摸牌、弃牌、鸣牌、跳过、结束事件。
- 实现 `StandardMahjongRuleEngine`：庄家起手、摸打、吃碰明杠、暗杠、加杠、尾部补张、点炮/自摸和、反应优先级和牌墙耗尽流局。
- 反应询问按和牌、碰/杠、吃分层并按放牌者顺时针距离选择；玩家跳过后继续寻找下一名合资格者，一炮只和最近一家。
- `GetLegalActions` 是玩家、AI 与后续提示/表现层的唯一操作来源，命令必须精确匹配实体牌操作后才会修改状态。
- 新增 `StandardMahjongScorer`，在公共层返回的全部和牌分解中选择最高番，独立计算基础和牌、自摸、门清、对对胡、混/清一色、七对、十三幺、三元刻与风刻，以及庄闲零和支付。
- 新增 `BasicStandardMahjongAi`，优先和牌/杠，进行基础吃碰，并按听牌种类数和孤张程度选择弃牌。
- 新增 `Game.Mahjong.Standard.Tests`，覆盖番型叠加、庄闲支付、合法弃牌、错误座位拒绝、反应优先级分层和批量完整对局。
- 新建并索引正式《大众麻将规则》，同步根 README 工程目录。

# 四川血战麻将规则

> 状态：已冻结。最后更新：2026-08-01。关联任务：[2026-08-01-011](../tasks/2026-08-01-011-四川血战麻将完整规则.md)。

## 牌与开局

- 四人使用万、筒、条三门数牌共 108 张，每种四张；无风牌、三元牌和花牌。
- 每家先得 13 张。四家各选同一门花色的三张牌，按本局确定性随机选出的顺时针、对家或逆时针方向同时交换。
- 收到三张牌后，每家声明万、筒或条为定缺门。庄家随后摸第一张牌并开始行牌。

## 定缺与行牌

- 手牌中只要还有定缺门的牌，自己的回合就只能弃该门牌。
- 四川血战不可吃；可以碰、点杠、补杠和暗杠。杠后从牌墙尾补一张。
- 和牌必须清空定缺门，并组成四面子一对或七对。
- 对同一张弃牌，所有能和的玩家按顺时针依次决定，允许一炮多响；只要有人和牌，该弃牌不再用于碰杠。
- 无人和牌时，碰/明杠按距放牌者顺时针最近者优先。

## 血战到底

- 自摸或点炮和牌者立即按当时番数结算并退出本局，此后不摸打、不响应，也不参与后续自摸或杠分支付。
- 行牌跳过已经和牌的座位。三家和牌后剩余一家自动结束；牌墙先摸完则进入流局检查。

## 番型与即时结算

基础番从 0 开始，支付单位为 `底分 × 2^番数`，默认底分 10，番数最高按 8 计算。

| 番型 | 番数 |
| --- | ---: |
| 平胡 | 0 |
| 对对胡 | 1 |
| 清一色 | 2 |
| 七对 | 2 |
| 龙七对（七对中含四张同牌） | 3，替代七对 |
| 金钩钓（四副露后单钓将） | 2 |
| 每一根（四张同牌） | 1 |

番型可叠加。点炮由放炮者独付一个单位；自摸由每名仍在战的其他玩家各付一个单位。每次和牌的变化均为零和。

## 刮风下雨

- 点杠：弃牌者向开杠者支付两个底分。
- 补杠：每名仍在战的其他玩家向开杠者支付一个底分。
- 暗杠：每名仍在战的其他玩家向开杠者支付两个底分。
- 已和牌退出者不再参与之后的杠分。

## 流局检查

- 流局检查只在当时仍未和牌、仍在战的玩家之间进行；此前已经和牌退出者不再收付。
- 查花猪：手中仍有定缺门牌者为花猪，向每名非花猪玩家支付 `底分 × 16`。
- 查大叫：排除花猪后，未听牌者向每名听牌者支付该听牌者当前等待牌中最高可成番数对应的一个支付单位。
- 已发生的和牌和杠分不退回；全部检查继续保持四家总变化为零。

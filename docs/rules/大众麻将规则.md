# 大众麻将规则

> 状态：已冻结。最后更新：2026-08-01。关联任务：[2026-08-01-010](../tasks/2026-08-01-010-大众麻将完整规则.md)。

## 牌局配置

- 四名玩家使用万、筒、条、东南西北、中发白共 136 张牌，不使用花牌。
- 每家起手 13 张，庄家额外摸一张并首先弃牌；之后按东、南、西、北顺序行动。
- 牌墙正常摸完且无人和牌时流局，本规则集不设荒牌听牌罚分。

## 行牌与鸣牌

- 自己回合摸牌后可以自摸和、暗杠、把已有明刻加杠，或弃一张牌；吃碰后不摸牌，直接弃牌；杠后从牌墙尾补一张。
- 只有放牌者的下家可以吃，且只能用同一数牌花色的连续三张；任意其他玩家可以碰或明杠同种牌。
- 反应优先级为点炮和牌 > 碰或明杠 > 吃；同级多人具备资格时，按距放牌者顺时针最近者优先。
- 一炮只允许一家和牌。玩家跳过当前最高优先级反应后，系统继续询问下一名有资格者；所有人跳过才由下家摸牌。
- 本规则集不采用抢杠胡、报听、吃后禁打同牌等地方附加限制。

## 和牌结构

- 普通形：四组顺子/刻子/杠加一对将。
- 七对：门前 14 张牌由七个不同牌种的对子组成；四张相同牌不拆成两个对子。
- 十三幺：十三种幺九字牌各一张，其中任意一种再成一对。
- 没有最低番门槛，符合以上任一结构即可和牌。

## 番型

每次和牌至少计“和牌”1 番，在同一个最终牌形上叠加以下番型并选择总番最高的合法分解：

| 番型 | 番数 |
| --- | ---: |
| 自摸 | 1 |
| 门前清 | 1 |
| 对对胡 | 2 |
| 混一色 | 3 |
| 清一色 | 6 |
| 七对 | 4 |
| 十三幺 | 13 |
| 每组中、发、白刻子或杠 | 1 |
| 自风刻子或杠 | 1 |
| 场风东刻子或杠 | 1 |

庄家为东座，因此东风刻在庄家手中可以同时取得自风与场风两番。

## 结算

- 基础单位为 `底分 × 2^(番数-1)`，默认底分 10，计算指数时番数最高按 13 处理。
- 点炮时由放铳者独付：赢家或放铳者任一为庄家时支付两个基础单位，否则支付一个。
- 自摸时：庄家自摸，三家各付两个基础单位；闲家自摸，庄家付两个基础单位、另两家各付一个。
- 四家分数变化之和始终为零；流局不改变分数。
